# Erid documentation

Erid is a unified golden-image pipeline and control plane for a hybrid cloud that
spans on-prem KVM/QEMU and AWS. It runs in production, hosting multiple services.

- **Architecture** - the pieces and how they fit.
- **Golden images** - the Packer pipeline across on-prem and multi-arch AWS.
- **Network and trust** - the private CA, mutual TLS, and mesh.
- **Nomad** - the orchestration variant and where it is going.
